# Privacy Policy for Currency in Words

Effective date: August 29, 2026

Currency in Words converts numeric amounts into localized currency words. This
policy explains how the extension handles information.

## Website content

The extension accesses only text that a user explicitly highlights before
selecting **Convert selection to currency words** from the right-click menu.
The selected text is processed locally in the browser to identify and convert a
numeric amount.

Highlighted text and conversion results are not transmitted to the developer or
third parties, stored after the conversion, sold, or used for advertising.

## Extension preferences

The extension stores the user's selected default currency and the time that
preference was updated. This preference is saved using Chrome Sync and local
extension storage so it can remain available when the extension is reopened.
The developer does not receive or access this preference.

## Data sharing

Currency in Words does not sell, rent, share, or transfer user data to the
developer, advertisers, analytics providers, or other third parties. The
extension contains no advertising, analytics, tracking, or external translation
service.

## Data retention and deletion

Highlighted website content and conversion results are not retained. The saved
default-currency preference remains in Chrome storage until the user changes it,
clears extension data, or removes the extension.

## Permissions

- **activeTab** provides temporary access to the current page after the user
  explicitly invokes the extension.
- **contextMenus** provides the right-click conversion command for selected
  text.
- **scripting** displays the local floating result card on the current page.
- **storage** saves the default-currency preference.

These permissions are used only to provide the extension's currency-conversion
features.

## Limited use

The use of information received from Chrome APIs complies with the Chrome Web
Store User Data Policy, including the Limited Use requirements. Information is
used only to provide the extension's disclosed, user-facing functionality.

## Changes to this policy

Material changes to this policy will be published in this repository and
disclosed as required by the Chrome Web Store policies.

## Contact

Questions, bug reports, and privacy concerns can be submitted through
